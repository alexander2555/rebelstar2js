# Research protocol

Primary target: Rebelstar II: Alien Encounter, ZX Spectrum 48K.

Use primary/historical sources for:
- controls
- map layout
- unit roster
- AP costs
- weapons
- ammunition
- damage
- accuracy
- mission objectives
- victory/defeat
- AI behavior
- timing

Suggested source categories:
- original manual
- original game/map
- archival screenshots
- documented historical implementations
- gameplay recordings

Every extracted rule should be recorded in `docs/REVERSE_SPEC.md` with:
- RULE-ID
- statement
- source
- confidence
- implementation status

Do not infer an exact numeric value from a modern remake unless no better evidence exists; if used, label it as secondary evidence.
